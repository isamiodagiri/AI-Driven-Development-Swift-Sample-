# 03 画面仕様

> **正**: 画面の構成・状態・文言。Figma は無いので**本ファイルがデザインの正**である。
> 実装で迷う値（余白・色）は DesignSystem のトークン名で書き、**View に数値を書かせない**（INV-6）。

---

## 0. 共通

### 0-1. タブ構成

`TabView` 2タブ。App 層が持つ。

| タブ | 画面 | アイコン |
|---|---|---|
| 検索 | A. 検索 | `magnifyingglass` |
| お気に入り | C. お気に入り | `star.fill` |

各タブが `NavigationStack` を1つ持ち、**B. 詳細はどちらのタブからも積める**。
`path` は App 層が `[Route]`（`enum Route: Hashable { case detail(RepoIDValue) }`）で持つ。

### 0-2. 状態の見せ方（3画面で共通の作法）

| 状態 | 見せ方 | 部品 |
|---|---|---|
| 読み込み中（初回） | **スケルトン行 × 6**（スピナーではない。確定時のレイアウトシフトを避ける） | `AppSkeletonRow` |
| 読み込み中（追加） | リスト末尾に小さいインジケータ。**既存の行は消さない** | `AppFooterSpinner` |
| 0件 | 説明文＋アイコン | `AppEmptyView` |
| 失敗 | 文言＋「再試行」ボタン | `AppErrorView` |
| レート制限 | 失敗の一種。**「あと N 分で再開できます」を出し、再試行ボタンは出さない** | `AppErrorView(variant: .rateLimited)` |

### 0-3. エラー文言（`AppErrorState` → 文言。ViewModel が決める）

| `GitHubError` | タイトル | 本文 | 再試行 |
|---|---|---|---|
| `.offline` | つながりませんでした | ネットワークの状態を確認してください | あり |
| `.timeout` | 時間がかかっています | 電波の良い場所でもう一度お試しください | あり |
| `.rateLimited(resetAt:)` | 回数の上限に達しました | あと **N 分**で再開できます | **なし** |
| `.notFound` | 見つかりませんでした | 削除されたか、非公開になった可能性があります | なし |
| `.invalidQuery(reason:)` | 検索できませんでした | 検索の条件を見直してください | なし |
| `.server` / `.unknown` / `.decoding` | 読み込めませんでした | 時間をおいてもう一度お試しください | あり |
| `.unauthorized` | 認証に失敗しました | アクセストークンの設定を確認してください | なし |

> **`resetAt` が無い `rateLimited`** は「あと 1 分で…」ではなく**「しばらく待ってからお試しください」**にする。
> 嘘の数字を出さない（`resetAt` は必ず来るとは限らない）。

## A. 検索画面（`SearchScreen`）

### A-1. レイアウト

```
┌──────────────────────────────┐
│ ⌕ [ リポジトリを検索        ] │ ← .searchable（NavigationStack 標準）
├──────────────────────────────┤
│ ┌──┐ apple/swift          ★67k│ ← RepoRowView（tap → 詳細）
│ │🖼│ The Swift Programming…    │
│ └──┘ ● C++   updated 3日前  ☆ │ ← ☆ お気に入りトグル
├──────────────────────────────┤
│ …（30件ごとに追加読み込み）    │
└──────────────────────────────┘
```

### A-2. 行（`RepoRowView` ← `RepoRowState`）

| 要素 | 内容 | 無いときの扱い |
|---|---|---|
| アバター | `owner.avatar_url`（40×40・角丸 `AppRadius.md`） | プレースホルダ矩形 |
| フルネーム | `full_name`（1行・省略記号） | — |
| 説明 | `description`（最大2行） | **行ごと出さない**（高さを詰める） |
| スター | `★ 67.0k`（1,000 以上は k 表記・小数第1位） | 0 のときも `★ 0` を出す |
| 言語 | 色ドット＋言語名 | **行ごと出さない** |
| 更新日 | 相対表記（「3日前」）。7日以上前は `yyyy/MM/dd` | — |
| お気に入り | `☆` / `★`（タップでトグル） | — |

- **k 表記の丸めは ViewModel が行う**（View は文字列を受け取るだけ）
- 相対表記は `RelativeDateTimeFormatter`。**基準時刻は注入する**（テストで固定するため）

### A-3. 状態遷移

| 現在 | 出来事 | 次 |
|---|---|---|
| `initial` | 検索語が空でなくなり 300ms 経過 | `loading` |
| `loading` | 成功・1件以上 | `loaded` |
| `loading` | 成功・0件 | `empty(query:)` |
| `loading` | 失敗 | `failed` |
| `loaded` | 末尾に到達 & `hasMore` | `loadingMore` |
| `loadingMore` | 成功 | `loaded`（**追記**） |
| `loadingMore` | 失敗 | `loaded` のまま＋**トースト**（一覧は消さない） |
| いずれか | 検索語が空になった | `initial`（**進行中の Task はキャンセル**） |
| `failed` | 「再試行」 | `loading` |

### A-4. 文言

- 未入力（`initial`）: 「リポジトリを検索」／「キーワードを入力すると、GitHub の公開リポジトリを検索します」
- 0件: 「“{query}” に一致するリポジトリはありません」／「別のキーワードでお試しください」

## B. 詳細画面（`RepoDetailScreen`）

### B-1. レイアウト

```
┌──────────────────────────────┐
│ ┌──┐ apple/swift           ☆ │
│ │🖼│ The Swift Programming…    │
│ └──┘                          │
├──────────────────────────────┤
│  ★ 67.0k  ⑂ 10.2k  👁 1.2k  ⓘ 340 │ ← AppStatBadge ×4
├──────────────────────────────┤
│ 言語     C++                  │
│ ライセンス Apache-2.0          │
│ 更新      2026/09/01           │
│ トピック  [swift][compiler]…   │
├──────────────────────────────┤
│ [ GitHub で開く ]              │ ← Safari（外部リンク）
└──────────────────────────────┘
```

### B-2. 「一覧の情報で描き始める」規約

詳細画面は **`RepoIDValue` ではなく、一覧が持っていた `RepoSummary` も受け取る**（無い場合＝
お気に入りタブからの遷移では `nil`）。

| 入口 | 初期表示 | 詳細取得の失敗時 |
|---|---|---|
| 検索一覧から | summary の内容を**即座に**描き、詳細だけ後から差し込む | **summary の表示は残す**＋下部に「詳細を読み込めませんでした・再試行」 |
| お気に入りから | `loading`（スケルトン） | 画面全体が `failed` |

> レート制限が 60/時であることへの直接の対策。**失敗しても白い画面にしない**。

### B-3. 表示の細目

- `archived == true` のとき、名前の下に「アーカイブ済み」バッジ
- `fork == true` のとき、名前の右に `⑂ フォーク` の小さい印
- `license == null` → 「ライセンス なし」。`topics` が空 → 行ごと出さない
- 「GitHub で開く」は `html_url` を `openURL`。**アプリ内 WebView は作らない**（スコープ外）

## C. お気に入り画面（`FavoriteScreen`）

### C-1. 仕様

- 端末に保存した**リポジトリの要約（`RepoSummary`）そのもの**を一覧する
  （ID だけを保存して毎回 API で引き直すと、レート制限を確実に使い切るため。裁定 D-5）
- 行は A の `RepoRowView` **と同じ見た目**にするが、**別ターゲットなので部品は `DesignSystem` に置く**
  （Feature 同士は参照できない ＝ INV-2）
- 並び順は **追加した新しい順**（`addedAt` の降順）
- スワイプで削除、`★` タップでも削除（削除は**確認ダイアログを出さない**。すぐ戻せるため）
- 0件: 「お気に入りはまだありません」／「検索した結果の ☆ を押すと、ここに集まります」

### C-2. 他画面との同期

**お気に入りの状態は1つの真実源（`FavoriteRepository`）から全画面へ流れる。**

```
FavoriteRepositoryImpl (actor)
   └── AsyncStream<[FavoriteRepo]> ──┬──> SearchViewModel.favoriteIDs   (@Published)
                                     ├──> RepoDetailViewModel.isFavorite (@Published)
                                     └──> FavoriteViewModel.items        (@Published)
```

- 検索一覧で ☆ を押したら、**お気に入りタブを開いた時ではなく即座に**そちらの一覧も変わる
- 画面ごとにローカルなフラグを持たない（**持つと必ずずれる**）
